## 📋 Описание файлов

### Главные модули

#### `main.py`
- Главное приложение с графическим интерфейсом PyQt5
- Создает окно приложения с панелями управления
- Обрабатывает события пользователя
- Управляет потоком обрезки видео

**Ключевые классы:**
- `VideoEditor(QMainWindow)` - главное окно приложения
- `VideoTrimThread(QThread)` - поток для обрезки в фоне

#### `video_processor.py`
- Основной класс для работы с видео файлами
- Загрузка информации о видео
- Обрезка видео с использованием FFmpeg
- Получение кадров для предпросмотра

**Ключевой класс:**
- `VideoProcessor` - обработчик видео файлов

#### `video_analyzer.py`
- Глубокий анализ видео файлов
- Получение детальной информации о потоках
- Оценка размера выходного файла
- Рекомендации оптимальных настроек

**Ключевые классы:**
- `VideoAnalyzer` - анализ видео
- `VideoOptimizer` - оптимизация и рекомендации

### Конфигурация и утилиты

#### `config.py`
Содержит все настройки приложения:
- Размеры окна и предпросмотра
- Поддерживаемые форматы видео
- Цвета интерфейса
- Параметры производительности

#### `logger.py`
Система логирования:
- Логирование в файл и консоль
- Разные уровни логирования (DEBUG, INFO, WARNING, ERROR)
- Форматирование с временем и источником

#### `operation_history.py`
Ведение истории операций:
- Сохранение информации о каждой обрезке
- Статистика (успешные/неудачные операции)
- Получение последних операций

#### `check_dependencies.py`
Проверка зависимостей:
- Проверка установки FFmpeg
- Проверка Python пакетов
- Информативные сообщения об ошибках

### Примеры и документация

#### `examples.py`
5 примеров использования API:
1. Базовая обрезка
2. Детальный анализ
3. Оценка размера
4. Проверка совместимости
5. Оптимальные настройки

### Скрипты и зависимости

#### `requirements.txt`
Список Python пакетов:
- PyQt5 - графический интерфейс
- ffmpeg-python - работа с FFmpeg
- opencv-python - анализ видео
- Pillow - обработка изображений
- numpy - работа с массивами

#### Скрипты установки и запуска
- `install.bat` - установка на Windows
- `run.bat` - запуск на Windows
- `run.sh` - запуск на Linux/macOS

### Документация

- `README.md` - основная информация о проекте
- `INSTALL.md` - подробная инструкция установки
- `USER_GUIDE.md` - руководство для пользователя

## 🔧 Использование компонентов

### Базовое использование

```python
# Импортируем основной класс
from video_processor import VideoProcessor

# Создаем экземпляр
processor = VideoProcessor()

# Загружаем информацию о видео
info = processor.load_video_info("video.mp4")
print(f"Длительность: {info['duration']} сек")

# Обрезаем видео
processor.trim_video("video.mp4", "trimmed.mp4", 10, 60)
```

### Продвинутое использование

```python
from video_analyzer import VideoAnalyzer, VideoOptimizer

# Анализируем видео
analyzer = VideoAnalyzer()
info = analyzer.get_detailed_info("video.mp4")

# Проверяем совместимость
compatibility = VideoOptimizer.get_stream_copy_compatibility(info)

# Получаем рекомендации
suggestions = VideoOptimizer.suggest_settings(info)

# Оцениваем размер
estimation = analyzer.estimate_output_size("video.mp4", 10, 60)
```

### С логированием

```python
from logger import logger
from operation_history import history

# Логируем операцию
logger.info("Начало обрезки видео")

# Сохраняем в историю
history.add_operation(
    input_file="video.mp4",
    output_file="trimmed.mp4",
    start_time=10,
    end_time=60,
    success=True
)

# Получаем статистику
stats = history.get_statistics()
print(f"Успешных операций: {stats['successful']}")
```

## 🚀 Производительность

### Характеристики

- **Загрузка информации:** < 1 сек
- **Предпросмотр кадра:** < 0.5 сек
- **Обрезка видео (stream copy):** 1-10 сек (зависит от размера)
- **Максимальный размер видео:** 10 GB+

### Оптимизация

- Многопоточность для обрезки (не блокирует UI)
- Ленивая загрузка кадров
- Кэширование информации о видео
- Stream copy вместо перекодирования
