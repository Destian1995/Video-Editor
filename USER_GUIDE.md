## 🎬 Основные функции

Video Editor позволяет:

- ✂️ **Обрезать видео** - удалить ненужные части видео
- 🚀 **Быстро** - используется stream copy (без перекодирования)
- 🎨 **Сохранить качество** - 100% исходное качество видео
- 🔊 **Сохранить аудио** - аудио дорожка остается нетронутой
- 📊 **Просмотреть информацию** - полная информация о видео

## ✂️ Как обрезать видео

### Способ 1: Используя слайдер

1. **Загрузите видео**
   - Нажмите кнопку "📁 Открыть видео"
   - Выберите MP4 файл

2. **Переместите слайдер**
   - Слайдер показывает текущую позицию в видео
   - Видео кадр обновляется в реальном времени

3. **Установите начало**
   - Переместите слайдер на нужное место
   - Скопируйте время из "Времени" в "Время начала"

4. **Установите конец**
   - Переместите слайдер в конец фрагмента
   - Скопируйте время в "Время окончания"

5. **Обрежьте**
   - Нажмите "✂️ Обрезать видео"
   - Файл сохранится в тот же папке

### Способ 2: Ввод времени вручную

1. Загрузите видео

2. Введите время начала:
   ```
   Время начала: 10 сек (или 0:00:10)
   ```

3. Введите время конца:
   ```
   Время окончания: 65 сек (или 0:01:05)
   ```

4. Нажмите "✂️ Обрезать видео"

### Время в разных форматах

- **Секунды:** `30` (30 секунд)
- **Минуты:Секунды:** `1:30` (1 минута 30 секунд)
- **Часы:Минуты:Секунды:** `0:01:30` (0 часов 1 минута 30 секунд)

## 💡 Советы и трюки

### Совет 1: Быстрая обрезка на ключевых кадрах

Stream copy (режим по умолчанию) обрезает только на ключевые кадры.
Это может означать, что результат будет примерно на 0-2 секунды отличаться от указанного.

**Решение:** Если нужна точная обрезка, используйте FFmpeg с перекодированием:
```bash
ffmpeg -i input.mp4 -ss 10 -to 60 -c:v libx264 output.mp4
```

### Совет 2: Пакетная обрезка

Для обрезки нескольких видео используйте командный файл:

**batch_trim.bat (Windows):**
```batch
@echo off
python -c "
from video_processor import VideoProcessor
processor = VideoProcessor()
processor.trim_video('video1.mp4', 'trimmed_video1.mp4', 10, 60)
processor.trim_video('video2.mp4', 'trimmed_video2.mp4', 20, 120)
echo Done!
"
```

### Совет 3: Проверка совместимости видео

Перед обрезкой вы можете проверить, совместимо ли видео со stream copy:

```bash
python -c "
from video_analyzer import VideoAnalyzer
analyzer = VideoAnalyzer()
info = analyzer.get_detailed_info('video.mp4')
print('Видео:', info['video'])
"
```

### Совет 4: Оценка размера файла

Перед обрезкой узнайте приблизительный размер выходного файла:

```bash
python -c "
from video_analyzer import VideoAnalyzer
analyzer = VideoAnalyzer()
est = analyzer.estimate_output_size('video.mp4', 10, 60)
print(f'Примерный размер: {est[\"estimated_output_mb\"]:.2f} МБ')
"
```

## ❓ FAQ

### Вопрос 1: Как быстро обрезать видео?

**Ответ:** Video Editor по умолчанию использует самый быстрый способ (stream copy).
Обрезка длится всего несколько секунд!

### Вопрос 2: Потеряется ли качество видео?

**Ответ:** Нет! При использовании stream copy качество сохраняется 100%.
Видео не перекодируется.

### Вопрос 3: Поддерживаются ли другие форматы?

**Ответ:** На данный момент хорошо поддерживается MP4.
Другие форматы (AVI, MOV, MKV) могут работать, но требуютFFmpeg.

### Вопрос 4: Как обрезать аудио?

**Ответ:** Аудио обрезается автоматически вместе с видео.
Если вам нужно работать только с аудио, используйте FFmpeg:
```bash
ffmpeg -i video.mp4 -ss 10 -to 60 -q:a 0 -map a audio.mp3
```

### Вопрос 5: Почему результат отличается на несколько кадров?

**Ответ:** Stream copy может обрезать только на ключевые кадры видео.
В зависимости от кодирования видео, это может быть на 0-5 кадров от указанного времени.

### Вопрос 6: Как получить точную обрезку?

**Ответ:** Используйте FFmpeg с перекодированием:
```bash
ffmpeg -i input.mp4 -ss 10 -to 60 -c:v libx264 -crf 23 output.mp4
```

Этот способ медленнее, но точнее.

### Вопрос 7: Где сохраняется обрезанное видео?

**Ответ:** В той же папке, что и исходное видео, с префиксом `trimmed_`.
Пример:
```
исходный файл: C:\Videos\MyVideo.mp4
обрезанный:    C:\Videos\trimmed_MyVideo.mp4
```

### Вопрос 8: Можно ли отменить обрезку?

**Ответ:** Исходное видео не изменяется, поэтому вы всегда можете повторить обрезку.

### Вопрос 9: Что если видео повреждено?

**Ответ:** Попробуйте переконвертировать видео:
```bash
ffmpeg -i corrupted.mp4 -c:v libx264 -c:a aac fixed.mp4
```

### Вопрос 10: Как использовать приложение из командной строки?

**Ответ:** Смотрите файл `examples.py` для примеров использования API.

```python
from video_processor import VideoProcessor
processor = VideoProcessor()
processor.trim_video('input.mp4', 'output.mp4', 10, 60)
```
